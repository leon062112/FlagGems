### PR Category

Operator

### Type of Change

Performance Optimization

### Description

Adds Hygon backend implementations of `sort` and `sort_stable`, with dispatch based on row length, row count, packed-key width and the input device's SM count.

- Use a dedicated packed-row kernel for contiguous rows up to 2048 elements, bypassing `libentry`, heuristics and generic strided parameters. For a singleton sort dimension, copy values and emit zero indices in one launch.
- Use packed-key tiled merge for larger rows and a stable four-pass 8-bit radix path for long 32-bit rows with at most 16 rows. FP16/BF16/INT16 retain the two-pass 16-bit radix criteria.
- Use single-warp initial runs for dense grids and stage-specific merge tiles. Skip merge-path partition searches when a program handles an entire pair of runs.
- Recover final values directly from packed keys where possible, preserving original signed-zero bits through a masked input load. Stable tie-breaking keeps original indices, and NaN keys are ordered after finite values in the 32-bit radix path.
- Use a wider 2048-element initial run for long 64-bit-key rows, keep a dedicated second scratch buffer, reuse the final index buffer as the alternate key buffer, and merge the first complete run pair per CTA when there are at most 16 rows.
- Support strided and non-last sort dimensions with tiled copies, and retain the generic implementation for unpackable 64-bit values and other unsupported layouts.
- Keep the existing public API.
